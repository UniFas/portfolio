The Things Left Behind

Can a game create sustained tension by controlling what the player knows, sees and expects, without ever attacking them?

  • Type: Design experiment / prototype
  • Runtime: 5-10 min
  • Role: Systems Designer, Prototyper
  • Engine: (your engine here)

01 · The Question

This isn't meant to prove mannequins are scary. It tests whether controlled information and violated expectations can change player behaviour with no chase, no combat and no scripted jumpscares.

Hypothesis: give players a reliable baseline, then expose them to small, deniable changes outside their observation, and they will start monitoring the environment and anticipating threats that may never come.

03 · The Observation Contract

A mannequin's state can only change while it is outside the player's direct field of view. If it is being watched, it is frozen. No exceptions.

The rule is enforced by real camera/player visibility, not scripted timing. A corner, a closing door or any blocking object counts as loss of observation. That reliability is what lets the player discover the rule, test it, and eventually fear it.

Memory → Evidence → Doubt

The camera preserves an earlier state of the room, so a photograph can contradict the player's memory.

04 · The System

Tension model

A hidden 0-100 value drives pacing across five stages:

  1. Normality: establish the baseline
  2. Doubt: small, deniable changes
  3. Awareness: pattern recognition
  4. Encroachment: changes in cleared spaces
  5. Final uncertainty: remove certainty instead of escalating

Event director

Events aren't random. The director reads the player's recent experience and expectations. If the player has been fixated on mannequins, it deliberately doesn't reward that, and shifts attention with an environmental anomaly first.
